# GTAVXR 1.0.5 public source components

This selection includes the following source components and the player guides.

| Folder | Contents |
| --- | --- |
| [Suite](../code/suite/README.md) | Suite UI, profile and maintenance logic, and build tools for synthetic fixtures |
| [OpenXR bridge](../code/bridge/README.md) | OpenXR bridge and graphics components, with CMake and shaders |
| VR policies under code/vr | Controls, calibration, HUD, and other VR logic from the public source selection |
| [Trainer](../code/trainer/README.md) | Trainer source, build instructions, and notices |

The public Suite build runs synthetic fixtures. The playable installer is available in [Releases](https://github.com/LVL-VR/GTAVXR/releases/latest).
